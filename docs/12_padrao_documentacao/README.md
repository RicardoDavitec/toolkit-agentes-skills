# 12 Padrão de documentação

Define **como** documentar qualquer projeto criado a partir deste template.
As pastas `00_` a `11_` dizem **onde** cada documento mora. Esta pasta diz **como** escrevê-lo, quando e com qual rastro.

| G01 | Visão geral do padrão | Todas |
| G02 | Hierarquia C / R / F / S / P | Todas |
| G03 | Nomenclatura e front matter | Todas |
| G04 | Fase F1 – Planejamento | F1 |
| G05 | Fase F2 – Implementação | F2 |

| G12 | LGPD e classificação | F1 a F5 |
| G13 | Diagramas como código | Todas |
| G14 | Cursor, extensões, agentes e skills | Todas |

## Subpastas

- `01_guias/` – estes guias.
- `02_modelos/` – um modelo por tipo de documento (nunca crie documento do zero).
- `03_exemplos/` – documentos de um projeto fictício, preenchidos.

## Como começar em 3 passos

1. Leia o G01 e o G02 (15 minutos).
2. Ao abrir uma fase, leia o guia dela (G04 a G08).
3. Antes de commitar, confira o G09.
