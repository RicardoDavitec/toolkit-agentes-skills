# Documentação acadêmica

Textos de pesquisa, artigos e material de apoio que não são o manual operacional do produto.

Subpastas sugeridas, só quando houver conteúdo: `capitulos/`, `artigos/`, `figuras/`, `manuais/`.

`livros/` é o lugar da coleção publicada (volumes, capítulos, figuras). No template essa pasta fica vazia.

`manuais/` guarda o manual de usuário em Markdown (HTML e PDF saem do build). O índice e as regras de versão ficam em `manuais/README.md`.
